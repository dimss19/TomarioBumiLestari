# TomarioBumiLestari

Website Profil Perusahaan Resmi untuk **CV. Tomario Bumi Lestari** - Produsen Material Batu Agregat Berkualitas & Kontraktor Konstruksi Umum (Gedung & Teknik Sipil).

## Gambaran Umum

CV. Tomario Bumi Lestari bergerak di bidang pengolahan batu andesit/basalt (stone crusher) dan kontraktor pelaksana konstruksi di Kabupaten Halmahera Utara, Maluku Utara.

## Teknologi

- **Framework**: Next.js 15 (App Router)
- **Bahasa**: TypeScript
- **Styling**: Vanilla CSS Modules & Global Design System
- **Tipografi**: Plus Jakarta Sans & Inter (Google Fonts)
- **Kompatibilitas**: Desain sepenuhnya responsif untuk desktop, tablet, dan smartphone

---

## Cara Menjalankan Secara Lokal

1. Pasang dependensi:
```bash
npm install
```

2. Jalankan server pengembangan:
```bash
npm run dev
```

3. Buka peramban di:
```
http://localhost:3000
```

4. Kompilasi build produksi:
```bash
npm run build
```
